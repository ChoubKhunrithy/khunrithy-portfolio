# Choub Khunrithy — Portfolio

A responsive, single-page developer portfolio built with plain HTML, CSS and JavaScript. No build tools or package installation required.

## Run locally

1. Extract the project folder.
2. Open `index.html` in a browser, or use VS Code with the Live Server extension.

## Publish with GitHub Pages

1. Create a new public GitHub repository (for example, `khunrithy-portfolio`).
2. Upload all files and folders from this project. Keep `index.html` at the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main** and **/(root)**, then Save.
6. Wait for GitHub Pages to publish the site.

## Before publishing

- Confirm the CV download file is the version you want public.
- Add your real GitHub and LinkedIn URLs when available.
- Replace the three project concept cards with verified screenshots, repository/demo links and accurate completion status. Their current descriptions are intentionally modest and should be reviewed.
- Confirm that you want your phone number, email and location displayed publicly.

## Files

- `index.html` — page content and sections
- `style.css` — responsive design and animations
- `script.js` — mobile navigation and reveal effects
- `assets/Choub-Khunrithy-CV.pdf` — supplied CV PDF
